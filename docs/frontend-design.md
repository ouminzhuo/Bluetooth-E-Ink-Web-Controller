# 前端设计示意图

## 1) 页面信息架构（IA）

```mermaid
flowchart TB
  A[页面 Header\n项目标题 + 规格说明] --> B[文本与版式]
  A --> C[字体设置]
  A --> D[预览与导出操作]
  A --> E[蓝牙发送面板]
  A --> F[SVG/Atkinson 预览区]

  E --> E1[连接桥接服务]
  E --> E2[发送参数\n分包大小/间隔]
  E --> E3[发送进度条]
```

## 2) 关键交互流程

```mermaid
sequenceDiagram
  participant U as 用户
  participant UI as 前端页面
  participant BR as 本地桥接服务
  participant BLE as 墨水屏设备

  U->>UI: 输入文本/设置字体与版式
  U->>UI: 点击“更新预览”
  UI->>UI: 生成 SVG + Atkinson 模拟
  U->>UI: 点击“发送当前画面”
  UI->>BR: send_frame(packet_id, chunk_size, payload)
  loop 分包发送
    BR->>BLE: write_gatt_char(chunk)
    BR-->>UI: progress(sent/total)
    alt ACK失败
      BR-->>UI: retry(group, attempt)
      BR->>BLE: 重发该组分包
    end
  end
  BR-->>UI: done(bytes/chunks)
  UI-->>U: 展示 100% 与成功状态
```
